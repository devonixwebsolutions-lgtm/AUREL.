# AUREL — Fintech Website

Complete source for the AUREL concept website. Built with plain HTML, CSS and JavaScript; no dependencies or build step required.

## Run
1. Extract this ZIP.
2. Open index.html in a modern browser.
Alternatively, open the folder in VS Code and use Live Server.

## Files
- index.html: page structure, copy, product showcase and setup dialog.
- style.css: responsive layouts, colours and animations.
- app.js: product tabs, scroll chapters, menu, setup guide and reduced-motion control.
- hero.webp: original AI-generated metallic sculpture used in the hero and closing sections.

## Customize
- Edit brand name and page copy in index.html.
- Edit the colours in :root at the beginning of style.css.
- Edit product copy and sample dashboard data in the products object in app.js.
- Edit the three scroll-driven principles in the chapters array in app.js.
- Replace hero.webp with your artwork using the same filename, or update its references in index.html and style.css.

## Publish elsewhere
Upload index.html, style.css, app.js and hero.webp together to any static website host. Keep them in the same directory.

## Scope
AUREL is a working concept brand. Financial values are sample data; this is a presentation website, not a banking application. The setup guide makes a local product recommendation. It does not create accounts, submit requests, move money or connect to financial services.

No third-party libraries, fonts, API keys or external network requests are required.
